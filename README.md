# Electricity Demand Analysis & Forecasting
Electricity Demand Analysis & Forecasting
A Data Science project for electricity demand prediction using EDA & Machine Learning.

🔹 Key Features
✅ Data Integration & Preprocessing: Handling missing values, feature engineering, and merging electricity demand & weather data.
✅ EDA & Outlier Detection: Time series analysis, IQR, and Z-score methods.
✅ Regression Modeling: Predicting electricity demand using ML models.
✅ Performance Evaluation: MSE, RMSE, and R² metrics.

📊 Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

📂 Project Structure
📁 electricity_raw_data/ → Raw electricity demand data

📁 weather_raw_data/ → Raw weather data

📄 processed_electricity_weather_data.csv → Cleaned & merged dataset

📜 robust_data_preprocessing.ipynb → Jupyter Notebook for data cleaning & analysis

📝 robust_data_preprocessing.py → Python script for automation
